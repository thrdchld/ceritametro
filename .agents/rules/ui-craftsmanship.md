# Antigravity UI/UX Craftsmanship & Anti-AI-Slop Rule

This rule ensures that any user interface components created or edited adhere to high-craft editorial web design principles.

### Principles:
1. **No Consumer Emojis as UI Icons**: Always use SVG icons (e.g. from `src/ui/icons.js`) with consistent stroke widths (1.75px) and monochrome styling.
2. **Warm Editorial Paper Palette**: Use warm organic neutrals (`#F7F5F2`, `#1A1615`, `#E5E0D8`) and mature plum/wine accents (`#4A2E4B`) instead of generic SaaS blue/purple gradients.
3. **Structured Whitespace**: Do not place cards inside cards. Rely on hairline dividers and generous, proportional whitespace.
4. **Editorial Typography**: Strict hierarchy with serif prose rendering, geometric sans headings, and monospace metadata badges.
5. **Tactile Micro-interactions**: Micro-scaling on press, crisp focus rings, smooth transitions.
